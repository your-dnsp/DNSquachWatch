# Optional configuration examples

These are templates for advanced features, not files required for normal operation.

- **dnsp-signatures.example.txt:** synthetic detection-rule format example. See the [research guide](../RESEARCH-GUIDE.md). Review your own rules before importing them as `/dnsp-signatures.txt` on microSD.
- **dnsp-telemetry.example.txt:** optional MAVLink-over-Wi-Fi settings. See the [field guide](../FIELD-GUIDE.md). Replace the example values before copying it as `/dnsp-telemetry.txt` on microSD. Never commit Wi-Fi passwords.
