# DNSquachWatch v1.7.4 — ILI9341-80MHz

This is the previously prepared ILI9341 build for classic 2.8-inch ESP32 CYDs, based on SquachWatch v1.30.0. It uses the exact DD:DD:DD simulation marker. The latest v1.8.1 release is ST7789 only.

Keep DNSP Content/v1.5 and flash the four supplied binaries without erasing saved settings. Serial uses 115200 baud; display starts at 80MHz and flash uses 40MHz. See the included installation and recovery documents.
