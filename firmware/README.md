# DNSquachWatch firmware downloads

Current release: **v1.5**. The primary [ST7789-80MHz kit](v1.5/ST7789-80MHz/DNSquachWatch-v1.5-ST7789-80MHz.zip) and [separate microSD content](v1.5/DNSquachWatch-v1.5-microSD-content.zip) are ready. [ILI9341-80MHz status](v1.5/ILI9341-80MHz/README.md) is updated after its separate build.

The firmware ZIP contains four images together at the top level. Copy DNSP Content from the card-content ZIP to the microSD root separately; esptool cannot populate the card. See [installation instructions](../INSTALL-CONTENT.md). A white screen can indicate the wrong CYD display controller; choose the other panel's kit when available. Old release folders remain for reference, not as the recommended download.
