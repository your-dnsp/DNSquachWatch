# Inherited upstream web-flasher source

This folder preserves upstream web-flasher source for reference. It is not the DNSquachWatch v1.5 installation route and is not deployed by DNSP's validation workflow. Its upstream multi-board manifests are not the DNSP release catalog. Use the [current DNSP kits](../firmware/README.md) and [manual/offline installation guide](../INSTALL-CONTENT.md). The DNSP device updater uses separately signed, board-specific files under ../ota/.
