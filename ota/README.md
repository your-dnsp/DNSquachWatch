# Signed receiver update endpoints

ST7789 (`cyd-fast`) is the only DNSquachWatch receiver release target. ILI9341 receiver support and update endpoints have been removed. DNSP uses ILI9341 boards for a separate simulation transmitter project.

Only board-matched signed images should be installed. ST7789 images must not be installed on ILI9341 panels. Private signing keys do not belong here.
