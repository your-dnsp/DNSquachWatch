# DNSP catalog font subset

Modified, generated subset of GNU Unifont 16.0.04 and its Japanese variant, redistributed under SIL Open Font License 1.1. Original licensing and contributor attribution accompany this file. Source: https://unifoundry.com/pub/unifont/unifont-16.0.04/

`glyphs.json` retains the selected source glyphs. `tools/build_languages.py` produces the shared bitmap blob and offset table in `include/language_data.h`; identical glyphs share bytes, and narrow glyphs use their actual width. This modified subset is named DNSP catalog font subset, not a standalone original Unifont release.
